## 2. 시연 순서

| 순서 | 화면 | 시연 행동 및 확인 포인트 | 실패 시 대응 |
|---|---|---|---|
| 1 | 스플래시 | 새 탭에서 `localhost:5173` 접속 → 토끼·거북이 달리기 로딩 바와 '출발 준비 중' (약 3초 뒤 자동으로 사라짐, 화면을 누르면 바로 넘어감) | 같은 탭에서 이미 봤으면 안 나옴. 보여 주려면 새 탭으로 접속 |
| 2 | 홈 (HOM-01) | 지도가 청량리역 근처로 이동하고 **'내 위치'** 스티커 표시 → 오른쪽 아래 확대·축소, **내 위치** 버튼 소개 → 위쪽 검색창은 글자를 치면 바로 자동완성이 뜬다고 소개 | 위치 권한이 없으면 서울시청 기준 지도와 '위치를 직접 설정해 주세요' 안내가 나옴. 체크리스트대로 Sensors 로 청량리역 지정 후 새로고침 |
| 3 | 외출 조건 설정 (CON-01) | 아래 **'외출 코스 추천받기'** → 출발지·도착지가 둘 다 **'현재 위치 : 건물·주소'** 로 채워진 것 확인 ('도착지도 기본은 현재 위치라 출발지로 돌아오는 코스'라고 설명) → 여유 시간이 **1h** 에서 시작하는 것 확인 후 슬라이더 **3h** (1~6시간, 종료 시각 자동 계산) → 이동수단은 기본 **도보** 그대로 → 카테고리는 기본이 **'랜덤 추천'** 인 것을 보여 주고, **'직접 선택' 버튼은 누르지 않고** 스티커 **음식/맛집 · 카페/디저트** 를 바로 눌러 자동으로 **'직접 선택'** 으로 바뀌고 '2 / 3개 골랐어요' 표시 확인 → **'추천받기'** | '추천받기'가 회색이면 출발지·도착지가 비었는지 확인 (위치 권한이 없으면 '현재 위치를 사용할 수 없어요' 안내). 비었으면 각 줄 → **'현재 위치 사용'**. 실수로 '직접 선택'을 눌러 문화생활이 골라졌으면 문화생활 스티커를 한 번 더 눌러 해제. 4번째 카테고리를 누르면 '최대 3개까지 고를 수 있어요' 토스트 (정상) |
| 4 | 추천 결과 (RES-01) | '딱 맞는 코스를 찾고 있어요' 로딩 → 코스 3개: 'N곳 · 이동 · 체류', 장소 순서와 장소 사이 이동시간 → 위쪽 카테고리 필터에서 대분류 하나 눌러 세분류 칩 보여 주고 **'전체'** 로 되돌리기 → **'다시 추천'** → 다른 코스 3개 | '잠시 후 다시 시도해 주세요' 토스트는 연속으로 눌러 제한에 걸린 것. 기다렸다 다시 누름. 로딩이 10초 넘게 걸려도 기다림 (실제 경로 계산 중) |
| 5 | 코스 지도 (DET-02) | 코스 카드 **'추천 1'** 선택 → 지도가 먼저 열림 → 1·2 핀과 **출발·도착 깃발**(출발지 = 도착지라 S 핀 없이 깃발 하나), **길을 따라 꺾이는 분홍 보행 경로선**(깃발 → 1 → 2 → 깃발로 돌아옴) 확인 → 아래 패널 '총 N분 · 이동 N분' → S → 1 → 2 칩에서 **'1'** 을 눌러 지도 이동과 장소 이름·시간 표시 확인 → **'코스 상세 보기'** | 지도가 안 뜨면 주소가 `localhost:5173` 인지 확인하고 새로고침. 경로가 직선이면 도보 경로 API 키(ORS) 문제 → '직선은 예상 경로'라고 설명하고 진행 |
| 6 | 코스 상세 (DET-01) | '코스 타임라인'과 '총 N분 · N곳', 장소별 방문 시각·체류·이동 확인 → 노란 **'카카오맵 길찾기'** → 카카오맵 도보 길찾기 패널 확인 → **'닫기'** | '카카오맵 길찾기'는 도보·차량 코스에만 있음. 패널이 비어 보이면 '닫기' 후 진행 |
| 7 | 장소 교체 (DET-03) | 2번 장소의 **'교체'** → '이 장소만 바꿔 볼까요?' → 후보별 이동시간과 '총 시간 +N분 / −N분' 비교 → 후보 하나 선택 → **'이 장소로 교체'** → 상세에서 2번 장소와 총 시간이 바뀐 것 확인 | '시간 초과' 후보는 고를 수 없다. 후보가 없으면 1번 장소로 시도 |
| 8 | 코스 저장 → 로그인 (AUT-01) | **'이 코스 저장하기'** (로그아웃 상태) → 로그인 화면 '코스를 저장하려면 로그인이 필요해요' → 시연 계정 입력 → **'로그인'** → 코스 상세로 돌아오며 **자동 저장** → 버튼이 **'저장됨 · 저장 취소'** 로 바뀌고 '코스를 저장했어요' 토스트 확인 | 로그인·저장이 '일시적인 오류'로 실패하면 DB 테이블 미생성 → 체크리스트 1번. **'저장됨 · 저장 취소' 버튼은 다시 누르지 않음** (저장이 취소됨) |
| 9 | 저장한 코스 상세 (MY-03) | 토스트의 **'저장한 코스 보기'** (3초 안에) → 'MM.DD 저장' 과 저장 당시 일정 확인 → 타임라인 1번 장소의 **'장소 상세'** → 장소 화면(지도 · 주소 · 카카오맵 장소 정보 시트) → 뒤로 → **'지도에서 보기'** → **'저장한 코스로 돌아가기'** | 토스트를 놓치면 하단바 **'저장한 코스'** → 방금 저장한 코스 선택 |
| 10 | 저장한 코스 목록 (MY-02) · 마이페이지 (MY-01) | 하단바 **'저장한 코스'** → '모아 둔 코스 N개' 와 방금 저장한 카드(총 시간 · N곳 · 'MM.DD 저장', '✕ 삭제') 확인 → 하단바 **'마이'** → 닉네임 '님'·이메일 프로필 카드와 '저장한 코스' 개수, '내 정보 관리'(회원 정보 수정 · 로그아웃) 보여 주기 | 목록이 비어 있으면 8단계 저장이 실패한 것 → 체크리스트 1번. **'✕ 삭제'·옆으로 밀기는 하지 않음** |
| 11 | 주변 장소 탐색 (HOM-02) | 하단바 **'주변 탐색'** → 반경 원과 분홍 묶음 숫자(클러스터), 내 위치와 겹친 묶음은 스티커 옆 배지로 표시 → 반경 버튼 **'3km'** → 카테고리 **'카페/디저트'** → 아래 세분류 칩 하나 눌렀다 다시 눌러 해제 → 작은 묶음(9곳 이하)을 눌러 **'이 근처 N곳'** 목록 확인 후 ✕ → 아래 카드 하나를 눌러 지도 이동·핀 강조 → **'상세 보기'** | 오류 문구와 '다시 시도'가 뜨면 한 번 누름. 계속 실패하면 녹화 영상으로 대체. 큰 묶음은 누르면 목록 대신 확대됨 (정상) |
| 12 | 장소 화면 · 화면 내 검색 | 장소 화면에서 **내 위치에서 장소까지 도보 경로**와 **'내 위치에서 도보 N분'** 배지, 주소, 아래 카카오맵 장소 정보 시트(영업시간·후기) 확인 → 뒤로 → 검색창에 **`카페`** 입력 → 자동완성에서 하나 골라 지도 이동·카드 강조 → 다시 **`카페`** 입력 후 엔터 → '반경 내' / '반경 밖' 으로 나뉜 결과와 반경 밖 핀이 흐리게 표시되는 것 확인 → ✕ 로 검색어 지우기 | 도보 경로는 주변 탐색에서 들어왔을 때만 나옴 (9단계 저장 코스의 '장소 상세'에서는 핀만, 정상). 내 위치에서 5km 넘는 장소도 핀만 나옴 (정상). 장소 화면에서 새로고침하면 '장소 정보를 다시 불러올 수 없어요' 가 나옴 (정상). 뒤로 가서 다시 선택 |

### 시연하지 않는 부분 (2026-11-19 기준)

| 기능 | 이유 |
|---|---|
| 비밀번호 찾기 | 메일 발송 기능 준비 중 (누르면 '준비 중' 알림만 뜸) |
| 회원 정보 수정·탈퇴 (MY-04) | 연결은 됐지만 탈퇴하면 시연 계정과 저장 코스가 지워짐. 질문이 나오면 '현재 비밀번호 + 동의 체크가 둘 다 있어야 탈퇴된다'고 화면만 보여 줌 |
| 저장 취소·저장한 코스 삭제 | 시연 중 저장한 코스가 사라짐. 질문이 나오면 '저장됨 · 저장 취소' 버튼과 '✕ 삭제' 위치만 설명 |
| 관리자 페이지 (`/admin`) | 관리자 계정이 있을 때만 들어감. 시간이 남으면 마이페이지 → '관리자 페이지' → 공지 등록 → 홈 공지 배너 확인 |
| 대중교통 실제 경로 | ODsay 키가 있을 때만 정류장을 잇는 경로. 이번 시연은 도보로 진행 |
