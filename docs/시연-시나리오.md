## 2. 시연 순서

| 순서 | 화면 | 시연 행동 및 확인 포인트 | 실패 시 대응 |
|---|---|---|---|
| 1 | 홈 (HOM-01) | 홈 접속 → 지도가 현재 위치로 이동하고 **'내 위치'** 스티커(분홍 후광) 표시 | 위치 권한이 없으면 서울시청 기준 지도와 '위치를 직접 설정해 주세요' 안내가 정상 동작임을 설명하고 진행 |
| 2 | 위치 설정 · 출발지 (CON-02) | **'지금 외출 추천'** → '출발지' 줄 → `성수` 검색 → **'성수역 2호선'** | 검색 결과가 안 나오면 '현재 위치 사용' |
| 3 | 위치 설정 · 도착지 (CON-02) | '도착지' 줄 → **'지도에서 직접 선택'** → 지도를 끌어 가운데 핀을 서울숲에 맞춤 → 아래 주소가 바뀌는 것 확인 → **'이 위치로 설정'** → 조건 화면 도착지에 반영 | 주소를 못 불러오면 **'다시 시도'**. 핀 맞추기가 어려우면 ← 로 돌아가 `서울숲` 검색 |
| 4 | 외출 조건 설정 (CON-01) | 이용 시간 **4h** → 이동수단 **도보** → 카테고리 **카페/디저트 · 음식/맛집** → **'추천받기'** → 로딩 화면 | '추천받기'가 회색이면 출발지가 비었거나 이용 시간이 0분인지 확인. 로딩이 길면(10초 이상) 기다림 — 이동 경로를 실제로 계산 중 |
| 5 | 추천 결과 (RES-01) | 코스 3개 확인: 장소 수 · 총 소요시간 · 장소 순서와 장소 사이 이동시간 → **'다시 추천'** → 다른 코스 3개 | '잠시 후 다시 시도해 주세요' 토스트가 뜨면 연속으로 눌러 제한에 걸린 것. 기다렸다 다시 누름 |
| 6 | 코스 상세 (DET-01) | **'추천 1'** 카드 선택 → 요약(총 소요시간 · 장소 수 · 도보)과 일정(방문 시각 · 체류 · 이동) 확인 | 소개가 없는 장소에는 '카카오맵에서 보기' 링크만 있다. 외부 사이트로 나가므로 누르지 않음 |
| 7 | 장소 교체 (DET-03) | 2번 장소의 **'교체'** → 후보 5곳의 이동시간과 총 시간 변화 비교 → 후보 하나 선택 → **'이 장소로 교체'** → 상세에서 2번 장소와 총 시간이 바뀐 것 확인 | '시간 초과' 후보는 고를 수 없다(이용 시간 초과). '이 장소로 교체'가 회색이면 후보를 먼저 선택 |
| 8 | 코스 지도 (DET-02) | **'지도에서 보기'** → S·1·2·3 핀과 도착 **E 깃발**, **실제 보행 경로선**(길을 따라 꺾이는 분홍 선) 확인 → **'1'** 핀을 눌러 말풍선(장소명 · 체류 · 다음 이동)과 핀 강조 → 아래 목록에서 **'3'** 을 눌러 지도 이동·강조 → 지도 빈 곳을 눌러 해제 → **'코스 상세로 돌아가기'** | 지도가 안 뜨면 주소가 `localhost:5173` 인지 확인하고 새로고침. 경로가 직선이면 도보 경로 API 키 설정 문제 → 이동수단 **차량**으로 다시 추천 |
| 9 | 로그인 (AUT-01) · 코스 저장 (DET-01) | **'이 코스 저장하기'** → 로그인 화면에서 시연 계정 입력 → **'로그인'** → 코스 상세로 돌아와 '저장됨' 표시와 토스트 확인 | 로그인이 '일시적인 오류'로 실패하면 DB 테이블 미생성 → 체크리스트 1번 확인 |
| 10 | 주변 장소 탐색 (HOM-02) | 홈에서 하단바 **'주변 탐색'** → 주변 장소 카드와 지도 핀 확인 → **'반경 3.0km'** → 카테고리 **'카페/디저트'** → 지도 핀을 눌러 해당 카드 강조 → 손잡이·제목으로 시트 접기·펼치기, 위로 끌어 전체 보기 | 오류 문구와 '다시 시도'가 뜨면 한 번 누르고, 계속 실패하면 녹화 영상으로 대체. **장소 카드는 누르지 않음** |
