## 2. 시연 순서

| 순서 | 화면 | 시연 행동 및 확인 포인트 | 실패 시 대응 |
|---|---|---|---|
| 1 | 홈 (HOM-01) | 홈 접속 → 지도가 현재 위치로 이동하고 현재 위치 스티커 표시 | 위치 권한이 없으면 서울시청 기준 지도와 '위치를 직접 설정해 주세요' 안내가 정상 동작임을 설명하고 진행 |
| 2 | 외출 조건 설정 (CON-01·CON-02) | **'지금 외출 추천'** → '출발지' 줄 → `성수` 검색 → **'성수역 2호선'** → 이용 시간 **5h** → 이동수단 **대중교통** → 카테고리 **랜덤 추천** → **'추천받기'** | '추천받기'가 회색이면 출발지가 비었거나 이용 시간이 0분인지 확인 |
| 3 | 추천 결과 (RES-01) | 코스 3개 확인: 장소 수 · 총 소요시간 · 장소 순서와 장소 사이 이동시간 | — |
| 4 | 추천 결과 (RES-01) | **'다시 추천'** → 다른 코스 3개 확인 ('예상 시간' 표시가 붙은 코스 포함) → **'다시 추천'** 한 번 더 → 처음 코스 3개 | 토스트 '잠시 후 다시 시도해 주세요'가 뜨면 2초 기다렸다 다시 누름 |
| 5 | 추천 결과 → 외출 조건 설정 → 추천 결과 | **'조건 바꾸기'** → 조건 화면에서 입력값 확인 → **'추천받기'** | — |
| 6 | 코스 상세 (DET-01) | **'추천 2'** 카드 선택 → 요약(총 4시간 31분 · 3곳 · 대중교통)과 일정(방문 시각 · 체류 · 이동) 확인 → **'전시관 A'** 를 눌러 소개 펼치기 | 소개가 없는 장소에는 '카카오맵에서 보기' 링크만 있다. 외부 사이트로 나가므로 누르지 않음 |
| 7 | 장소 교체 (DET-03) | '카페 B'의 **'교체'** → 후보 5곳의 이동시간과 **총 시간 변화(−3분 ~ +12분)** 비교 → **'카페 H (−3분)'** 선택 → **'이 장소로 교체'** → 상세에서 2번이 카페 H, 총 4시간 28분으로 바뀐 것 확인 | '이 장소로 교체'가 회색이면 후보를 먼저 선택. 이용 시간을 넘으면 '선택한 시간을 넘어요' 안내가 뜬다 |
| 8 | 코스 지도 (DET-02) | **'지도에서 보기'** → S·1·2·3 핀과 경로선 확인 → **'1'** 핀을 눌러 말풍선(장소명 · 체류 · 다음 이동) → 아래 목록에서 **'3 볼링장 C'** 를 눌러 지도 이동 → **'코스 상세로 돌아가기'** | 지도가 안 뜨면 주소가 `localhost:5173` 인지 확인하고 새로고침 |
| 9 | 코스 저장 (DET-01 → 로그인 AUT-01) | **'이 코스 저장'** → 로그인 화면에서 시연 계정 입력 → **'로그인'** → 코스 상세로 돌아와 '저장됨' 표시와 토스트 확인 | 이메일 형식 오류 문구가 뜨면 입력값 확인 |
| 10 | 저장한 코스 (MY-02 → MY-03 → DET-02) | 토스트의 **'저장한 코스 보기'** → 저장한 코스 선택 → '저장 시점 정보' 확인 → **'지도에서 보기'** → **'저장한 코스로 돌아가기'** | 토스트가 사라졌으면 ← 로 홈까지 가서 하단바 **'저장한 코스'**. 목록이 비어 있으면 새로고침한 경우라 6단계부터 다시 |
| 11 | 주변 장소 탐색 (HOM-02) | 홈에서 하단바 **'주변 탐색'** → 주변 장소 카드와 지도 핀 확인 → 반경 **'3.0km'** → 카테고리 **'카페/디저트'** → 지도 핀을 눌러 해당 카드 강조 → 손잡이·제목으로 시트 접기·펼치기, 위로 끌어 전체 보기 | 오류 문구와 '다시 시도'가 뜨면 한 번 누르고, 계속 실패하면 녹화 영상으로 대체. 장소 카드는 누르지 않음 (장소 상세 연결 전) |
