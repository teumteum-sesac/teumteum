# 틈틈 시연 시나리오 (NFR-039)

> 담당: 유지수 · 상태: 초안 · 기준: `dev` `67cdb2c` (2026-11-17)
> 화면별 상세 동작은 [화면설계서](틈틈%20화면설계서.md), 요구사항은 [요구사항 정의서](requirements.md)를 따른다. 이 문서는 **시연 순서와 현재 연결 상태**만 다룬다.
> 🔄 표시는 팀원 API 연결이 끝나면 갱신할 항목이다.

## 0. 현재 연결 상태 요약

| 구분 | 해당 기능 |
|---|---|
| ✅ 실제 데이터 | 주변 장소 탐색 목록·지도 핀 (`GET /api/places/nearby`), 현재 위치(브라우저 위치), 카카오 지도 |
| ⚠️ 목업 (서버 호출 없음) | 홈 검색창, 위치 검색, 추천 결과·코스 상세·코스 지도·장소 교체, 로그인·회원가입, 코스 저장·저장한 코스 |
| 백엔드 API는 있으나 화면 미연결 | 로그인·회원가입, 저장 코스 목록·상세·삭제, 장소·주소 검색, 좌표→주소 |
| 백엔드 미구현 | 추천 API (코스 구성 로직까지 #94), 코스 저장 API, 장소 상세 API |

목업 구간에서 알아 둘 점:

- 추천 결과는 **고른 조건과 상관없이** 출발지 '성수역 2호선', 도착지 없음으로 고정된 코스가 나온다. 그래서 도착지 깃발(E)은 지금 시연할 수 없다
- 로그인은 이메일 형식과 비밀번호만 입력하면 서버 확인 없이 된다 (로그인 상태는 새로고침해도 유지)
- 저장한 코스는 브라우저 메모리에만 있어 **새로고침하면 사라진다**

## 1. 시연 순서

| # | 단계 | 화면 ID · 경로 | 시연 행동 | 정상 결과 | 연결 상태 |
|---|---|---|---|---|---|
| 1 | 홈 | HOM-01 `/` | 위치 허용 후 홈 진입 | 지도가 현재 위치로 이동하고 현재 위치 스티커 표시. '남는 시간, 어디로 가볼까요?' 아래 '지금 외출 추천'·'주변 장소 탐색' 버튼 | 지도·위치 ✅ / 홈 검색창 ⚠️ 목업 🔄 정종일 |
| 2 | 외출 조건 설정 | CON-01 `/condition` | '지금 외출 추천' → 출발지가 '현재 위치'인지 확인 → 이용 시간 2시간 → 이동수단 도보 → 카테고리 '카페/디저트' → '추천받기' | 출발지와 이용 시간이 있어야 '추천받기' 활성 (0분이면 비활성) | 화면 동작 ✅ (서버 호출 없음) / 위치 검색(CON-02) ⚠️ 목업 🔄 정종일 #92 / '지도에서 직접 선택'은 '준비 중' 🔄 정종일 (핀 컴포넌트 #88 완료) |
| 3 | 추천 결과 | RES-01 `/results` | 코스 3개 훑기 → '다시 추천' 한 번 | 코스 카드 3개, '다시 추천' 시 다른 조합. 연달아 누르면 잠시 후 다시 시도 안내 | ⚠️ 목업 (조건 무관 고정 코스) 🔄 나혜빈 (추천 API) |
| 4 | 코스 상세 | DET-01 `/results/:courseId` | 첫 코스 선택 → 일정 확인 → 장소를 눌러 사진·소개 펼치기 | 출발지 → 장소 순서, 방문 시각·체류·이동시간, '이동·체류시간은 예상값' 안내 | ⚠️ 목업 🔄 김용현 (DET-01 연결), 나혜빈 (추천 상세 API) |
| 5 | 코스 지도 | DET-02 `/results/:courseId/map` | '지도에서 보기' → 번호 핀 눌러 말풍선 → 아래 목록 항목 눌러 지도 이동 → '코스 상세로 돌아가기' | S·1·2 핀, 핑크 경로선, 말풍선(장소명·체류·다음 이동), 총·이동 시간, 코스 상세로 복귀 | 지도 그리기 ✅ (#51·#66·#95) / 코스 데이터 ⚠️ 목업 → 경로는 직선만 🔄 김용현·나혜빈 (도보·차량 실제 경로, 도착 깃발) |
| 6 | 코스 저장 | DET-01 → AUT-01 `/login` | (로그아웃 상태에서) '이 코스 저장' → 로그인 화면에서 이메일·비밀번호 입력 → 로그인 | 로그인 후 코스 상세로 돌아와 자동 저장, '저장됨' 토스트 | ⚠️ 로그인 목업 🔄 김용현 / ⚠️ 저장은 메모리 🔄 김하윤 (저장 API) |
| 7 | 저장한 코스 확인 | MY-02 `/mypage/courses` → MY-03 → DET-02 | 토스트의 '저장한 코스 보기' → 코스 선택 → '저장 시점 정보' 확인 → '지도에서 보기' → '저장한 코스로 돌아가기' | 저장한 코스 1개, 상세, 지도, 저장한 코스 상세로 복귀 | ⚠️ 목업 (메모리) 🔄 김하윤 #91 (목록·삭제), 김용현 (MY-03·지도) |
| 8 | 주변 탐색 | HOM-02 `/nearby` | 하단바 '주변 탐색' → 반경 500m·3km 바꾸기 → 카테고리 칩 → 지도 핀 눌러 카드 강조 → 시트 끌어 올리고 내리기 | 실제 주변 장소 카드·핀 (성수역 1km 기준 약 200곳, 응답 1~2초). 반경을 바꾸면 다시 불러오고 칩은 바로 거름 | ✅ 실제 API (#84) / ⚠️ **카드는 누르지 않기**: 장소 1곳짜리 상세가 아직 목업 ID만 지원해 '만료' 화면이 나옴 🔄 나혜빈·김용현·정종일 (처리 방식 결정) |

## 2. 시연 전 준비

| 항목 | 내용 |
|---|---|
| 서버 | 백엔드 8080 (`backend` 에서 `gradlew.bat bootRun`), 프론트 5173 (`frontend` 에서 `npm run dev`). 카카오 지도 키가 `localhost:5173` 에 등록돼 있어 다른 포트에서는 지도가 안 뜬다. 배포 환경으로 시연하면 그 도메인을 카카오에 등록해야 한다 🔄 김용현 (배포 방식 미정) |
| 설정 | 백엔드 `application-local.yml` (DB 비밀번호·카카오 REST 키·JWT 비밀키), 프론트 `.env.local` (지도 키). 값은 공유 문서에 적지 않는다 |
| DB | MySQL 실행 + `teumteum` DB (없으면 서버가 시작되지 않음). 지금 시연 구간은 테이블을 쓰지 않는다. 저장 API 연결 후에는 [ERD](erd.md) DDL로 테이블 생성 🔄 |
| 테스트 계정 | 지금은 로그인 목업이라 아무 값 (예: `demo@teumteum.app` / 아무 비밀번호). 로그인 연결 후에는 미리 가입한 시연 계정 사용 🔄 김용현 |
| 위치 권한 | 시연 브라우저에서 위치 '허용'. 목업 추천이 성수역 기준이라 위치도 성수역(37.5446, 127.0559)이면 화면이 자연스럽다. 실내에서 위치가 튀면 개발자 도구 Sensors 로 지정 |
| 추천 데이터 | 지금은 목업이라 준비 불필요. 추천 API 연결 후에는 시연 위치·시간·카테고리 조합을 미리 돌려 코스 3개가 나오는 조건을 정해 둔다 🔄 나혜빈 |
| 화면 크기 | 개발자 도구 기기 모드(375px) 또는 실제 휴대폰 |
| 대체 자료 | 단계별 화면 녹화 또는 캡처 (API 실패 대비) |

참고: 주변 탐색 1번 조회에 카카오 장소 API를 약 27번 부른다. 리허설을 여러 번 하면 무료 한도를 확인한다.

## 3. 실패·예외 시 대체 시연

| 상황 | 화면에 보이는 것 | 대체 방법 |
|---|---|---|
| 주변 장소 API 실패 (서버 꺼짐·카카오 오류) | 시트에 오류 문구 + '다시 시도' | '다시 시도' 1번 → 백엔드 상태 확인 → 안 되면 오류 안내 화면 자체를 보여 주고 녹화 영상으로 넘어간다 |
| 위치 권한 거부·위치 오류 | 서울시청 기준 지도 + '위치를 직접 설정해 주세요' 안내 | REQ-037 의 정상 동작으로 설명하고 진행. 주변 탐색은 서울시청 기준으로 조회된다 |
| 추천 결과 없음 (추천 API 연결 후) 🔄 | '조건에 맞는 코스가 없어요…' + '조건 바꾸기' | 안내 화면을 보여 준 뒤 시간을 늘리거나 카테고리를 줄여 다시 추천. 미리 확인한 조건 사용 |
| 추천 만료 (2시간) | '추천이 만료되었습니다…' | 같은 조건으로 다시 추천 |
| 지도가 안 뜸 | '지도를 불러오지 못했어요…' | 5173 포트(또는 등록 도메인)인지 확인 후 새로고침 |
| 저장한 코스가 사라짐 | 저장한 코스 목록이 비어 있음 | 새로고침 때문. 6단계(코스 저장)부터 다시 |

## 4. 시연 직전 체크리스트

- [ ] 최신 `dev` 기준으로 실행, 백엔드 시작 로그에 `Started` 확인
- [ ] `http://localhost:8080/api/places/nearby?lat=37.5446&lng=127.0559&radius=1000` 응답 200
- [ ] 브라우저 위치 허용, 홈에서 현재 위치 스티커 확인
- [ ] 주변 탐색에서 카드·핀이 뜨는지 한 번 확인
- [ ] 6단계 로그인 흐름을 보여 주려면 **로그아웃 상태**로 시작 (마이페이지 → 로그아웃)
- [ ] 6~7단계 사이에 새로고침하지 않기
- [ ] 375px 기기 모드 또는 실제 휴대폰
- [ ] 대체 자료(녹화·캡처) 준비
